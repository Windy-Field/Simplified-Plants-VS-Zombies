# 可新增的创意技能

本文件记录以后可以加入游戏的植物和僵尸技能。每个技能都先按“资料字段 + 通用行为”设计，只有现有行为无法表达时，才新增专门的处理类。

## 设计原则

1. 先确认技能的触发条件、持续时间、目标范围和结束方式。
2. 能写进 `PlantDefinition` 或 `ZombieDefinition` 的差异，不要散落成多个名字判断。
3. 技能需要新动画时，先把动画放入 `assets/new_assets/`，再在 `Assets.java` 中登记。
4. 每个技能都要补充 `SelfCheckTest`，至少检查触发、持续、结束和异常情况。
5. 范围、伤害、冷却和速度等会调整的数值，集中放入 `Layout` 或 `CombatValues`。

## 植物技能

| 技能 | 玩法 | 建议复用位置 | 需要的素材 |
| --- | --- | --- | --- |
| 连锁豌豆 | 子弹命中后跳向附近的第二只僵尸，伤害逐次降低 | `ShooterActions`、`Bullet` | 连锁命中特效 |
| 穿透攻击 | 一颗子弹连续穿过同一行的多只僵尸 | `ShooterActions` | 可复用现有子弹 |
| 反弹攻击 | 子弹碰到边界或僵尸后改变方向 | `Bullet`、`Layout` | 反弹特效，可选 |
| 冰冻区域 | 生成持续数秒的寒冰区域，减慢范围内的僵尸 | `InstantPlantActions`、`CombatSystem` | 冰雾或冰面动画 |
| 阳光护盾 | 消耗一定阳光，为一株植物抵挡一次伤害 | `Plant`、`PlantActions` | 护盾动画 |
| 阳光转化 | 将收集到的阳光转化为短时间的攻击或生产加成 | `GameState`、`SunProducerActions` | 增益图标 |
| 地刺升级 | 地刺受到特定植物或阳光强化后，攻击范围和伤害提高 | `PlantDefinition`、`CloseAttackActions` | 升级前后动画 |
| 诱捕植物 | 在地面生成陷阱，僵尸踩中后短暂停止 | `CloseAttackActions` | 陷阱、触发和消失动画 |
| 召唤植物 | 植物周期性召唤一次性子弹或小型植物 | `PlantActions` | 召唤物和召唤特效 |
| 变色豌豆 | 子弹根据经过的植物改变为火、冰或普通属性 | `BulletTransformation` | 对应子弹素材 |
| 时间暂停 | 一次性植物让范围内僵尸暂停，植物和阳光继续运行 | `InstantPlantActions`、`Zombie` | 时间停止特效 |
| 传送植物 | 将同一行最靠前的僵尸传送到更远位置 | `CloseAttackActions`、`Zombie` | 传送起点、终点和残影 |

## 僵尸技能

| 技能 | 玩法 | 建议复用位置 | 需要的素材 |
| --- | --- | --- | --- |
| 冲刺 | 僵尸短时间提高移动速度，结束后进入冷却 | `ZombieDefinition`、`Zombie` | 冲刺动画或残影 |
| 护盾 | 护盾存在时抵挡子弹，护盾破坏后露出本体 | `ZombieDefinition`、`ZombieEffects` | 护盾、破碎和受击动画 |
| 跳跃 | 跳过一株植物并落到下一格 | `Zombie`、`CombatSystem` | 起跳、空中和落地动画 |
| 挖地 | 僵尸短时间隐藏，从植物后方或指定位置出现 | `Zombie`、`LevelSystem` | 地面、下潜和出现动画 |
| 偷取阳光 | 僵尸接近阳光时优先吃掉阳光，减少玩家资源 | `CombatSystem`、`Sun` | 偷取动作和阳光飞行效果 |
| 召唤小鬼 | 僵尸死亡或到达某位置时召唤小鬼僵尸 | `ZombieEffects` | 召唤特效，可复用小鬼动画 |
| 伪装 | 僵尸初始显示为普通僵尸，受击后显露真实类型 | `ZombieDefinition`、`Zombie` | 伪装和显露动画 |
| 水上移动 | 僵尸只能在泳池行移动，离开水面后速度降低 | `ZombieDefinition`、`LevelSystem` | 水花和入水动画 |
| 推进装甲 | 僵尸推动植物或其他僵尸，改变前方对象的位置 | `Zombie`、`CombatSystem` | 推动动作，可复用行走动画 |
| 狂暴 | 失去装备后速度和攻击间隔发生变化 | `ZombieDefinition`、`Zombie` | 狂暴或受伤状态动画 |
| 远程投掷 | 僵尸从远处向植物投掷物体 | `CombatSystem`、`Bullet` | 投掷物和攻击动画 |
| 复制 | 僵尸复制附近的一只普通僵尸，但复制体血量较低 | `ZombieEffects`、`ZombieCatalog` | 复制特效 |

## 优先级建议

第一批适合实现的技能是穿透攻击、冰冻区域、护盾、冲刺和跳跃。这些技能可以复用现有的子弹、范围效果、动画状态和僵尸移动逻辑，改动范围较小，也容易写出稳定的自检。

第二批可以实现连锁豌豆、诱捕植物、召唤小鬼、偷取阳光和挖地。这些技能会增加对象之间的交互，需要同时检查目标选择、对象回收和边界情况。

时间暂停、传送植物、复制和推进装甲会改变整局战斗的节奏或对象位置，建议在基础技能稳定后再实现。

## 每个技能的自检清单

- 正常触发：满足条件时技能只触发一次。
- 目标选择：范围边界、同排判断和阵营判断正确。
- 持续时间：技能结束后速度、动画、护盾和状态能够恢复。
- 多目标：同时存在多个目标时不会漏判或重复处理。
- 对象回收：子弹、特效、召唤物和临时状态结束后都会被清理。
- 关卡兼容：正常关卡、传送带关卡和保龄球关卡不会互相影响。
- 素材检查：所有动画和图片都加入通用自检。
